# Бот лобби для Standoff 2 (закрытый доступ, управление кнопками)

Из команд нужна только `/start`, дальше кнопки. Текстом вводятся только ник/ID (один раз) и свой вариант «на чём играем».

## Доступ

- Без доступа бот пишет «Нет доступа», показывает ID и кнопку **«Запросить доступ»**.
- Запрос приходит админам с кнопками **«Выдать доступ»** / **«Отклонить»**. Человеку бот сам напишет, когда доступ выдан.
- Админ: **Меню → Доступы** — список запросов (✅ выдать, 🚫 отклонить) и людей с доступом (нажать, чтобы забрать).
- Админы (`ADMIN_IDS`) имеют доступ всегда. `ALLOWED_IDS` — постоянный список, не пропадает при перезапуске.
- Кнопка «ПОДКЛЮЧИТЬСЯ» под постом в канале работает у всех — игрокам доступ не нужен.

## Меню

- **Создать ДМ**: на чём играем → карта → урон → время → предпросмотр → «Опубликовать в канал».
  «На чём играем» можно выбрать кнопкой или нажать «✏️ Написать свой вариант» и написать текстом (например, «калаш БЕЗ ОБНОВЫ»).
  На каждом шаге есть «Назад» и «Меню». Ник и ID в Standoff 2 бот спрашивает один раз и запоминает;
  изменить можно кнопкой в предпросмотре или в меню.
- **Активные лобби**: список с кнопками «Закрыть #N» (админу видны все лобби и есть «Закрыть все»).
- **Мой ник и ID**.
- По окончании времени пост в канале сам помечается закрытым.

Пост в канале:

```
📢 Лобби #937 создано!

👤 Хост: nights 80000800
🎮 Режим: ДМ
🎯 Урон: Только ХС
🗺 Карта: dune
⏱ Длительность: 10 минут
⚔ На чём: usp

─────────────────
👇 Жми и врывайся в бой! 👇
[ 🚀 ПОДКЛЮЧИТЬСЯ ]
```

Варианты кнопок («какой ДМ», карты, урон, время) меняются в настройках `WEAPONS`, `MAPS`, `DAMAGES`, `MINUTES`.

## Развёртывание на Bothost

Файл запуска `bot.py` лежит в корне, зависимости ставятся из `requirements.txt` — Dockerfile не нужен.

1. Загрузите файлы на Bothost: подключите Git-репозиторий (GitHub/GitLab) или загрузите через веб-интерфейс.
   Файл `.env` в публичный репозиторий не кладите.
2. Задайте переменные в панели (на платных тарифах): `BOT_TOKEN`, `CHANNEL_ID`, `ADMIN_IDS`
   (остальные из `.env.example` по желанию). Запасные имена `TOKEN` и `CHAT_ID` тоже работают.
   Если переменных на вашем тарифе нет, загрузите файл `.env` вместе с ботом (только в приватный репозиторий или через веб-загрузку).
3. Добавьте бота в канал администратором с правом публикации.
4. Нажмите Deploy и отправьте боту `/start`.

### Про сохранение данных

- На **бесплатном** тарифе Bothost данные стираются при перезапуске: пропадут выданные доступы, ники и нумерация лобби.
  Впишите людей в `ALLOWED_IDS`, а номер продолжайте через `COUNTER_START`.
- На платном тарифе с постоянным диском (Volume) укажите в `DATA_FILE` путь к диску, например `DATA_FILE=/data/data.json`
  (точный путь смотрите в панели хостинга) — тогда всё сохраняется.
